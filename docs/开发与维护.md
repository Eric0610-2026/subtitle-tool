# 开发与维护

本指南面向维护者。用户安装与操作见 [README](../README.md) 和 [使用说明书](使用说明书.md)；模块职责、事件契约和架构约束见 [AGENTS.md](../AGENTS.md)。以下命令在项目根目录的 Windows PowerShell 中执行。

## 修改前

1. 阅读 AGENTS.md，执行 `git status --short`，确认并保留已有改动。
2. 添加新功能前向用户确认；需求不明确时先确认范围。修正文档时以当前实现、配置模板和测试为依据。
3. 精准查找相关模块，避免为了解一个行为通读所有大文件。核心模块、数据流或配置结构变更后同步维护 AGENTS.md 与 README。

## 环境与运行

建议创建独立环境，并在后续命令中使用同一解释器：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r tools/requirements.txt
npm ci
npx install-electron
npm start
```

实际运行需要按 README 准备 ffmpeg/ffprobe、Whisper 模型和按需使用的 llama.cpp、Hy-MT2 模型。单元测试通过模拟调用运行，无需下载或加载模型。

Electron 主进程通过标准输入输出向 `python -m subtitle_app.electron_backend` 发送逐行 JSON 请求。后端返回带请求编号的结果，主动推送进度、日志与字幕。后台线程复用 `SubtitleWorker`，每轮冻结设置。下载器通过原有本机端口追加任务。渲染进程通过预加载脚本提供的接口调用后端。

双击根目录的 `字幕工具.exe`，按 EXE 所在目录定位 Electron 和工作目录。后端优先使用项目 `.venv/Scripts/python.exe`，否则从 PATH 查找 `python.exe`。移动前彻底退出应用。项目内模型通过设置界面保存为相对路径。

## 配置与文件归属

修改 `tools/launcher.cs` 或 `subtitle_app/icon.ico` 后，运行 `& ./tools/build-launcher.ps1` 重建带图标的启动器。脚本使用 Windows 自带的 .NET Framework C# 编译器。启动器测试用临时原生窗口探针验证中文和特殊字符目录移动后仍可定位运行环境。

| 路径 | 维护规则 |
| --- | --- |
| `subtitle_app/config.example.json` | 提交到仓库的默认配置模板；改变默认值应修改此处 |
| `subtitle_app/config.json` | 本机设置，不提交；缺失时读取模板，已有配置缺少的字段由模板补齐 |
| `models/`、`tools/llama-cpp/` | 本地模型与推理程序，不随源码分发 |
| `cache/` | 翻译缓存、已完成记录和本地服务日志；不能当作无差别可删的临时目录 |
| `logs/` | 应用日志与 `srt_backup/` 字幕备份；排障或迁移前保留所需内容 |
| 输入媒体所在目录 | 输出字幕、视频及断点文件；测试不得使用真实用户媒体 |

「本次有效」影响当前会话随后启动的任务；「永久保存（下次默认）」还写入本机配置。正在运行的任务使用启动时冻结的快照。手工修改配置后重启应用；重置前可先备份自己的配置文件。

## 验证

人名译法由设置界面按目标语言维护在 `translation.name_glossaries`，任务开始时冻结为普通字典。整句与原名一致时直接输出指定译法；句内人名加入模型提示词，模型误用其他已配置人名时按原文唯一人名纠正。两个字符以内的平假名只在句首或分隔符后识别，避免「足りない」「触りながら」等普通词误命中；因此紧接汉字或假名的人名可能漏检，优先保留原句语义。原文及译文通过统一匹配器按长名优先取不重叠片段；ASCII 英文名检查左右字母、数字及下划线边界，片假名检查两侧片假名边界。译文以原始片段一次替换并保护已配置译名，避免级联替换；原文多人名分别处理，原文单人名且译文尚无对应原名或正确译名时才尝试纠正其他已配置人名。同形的正确译名与原名有歧义时优先保留正确译名。批量及纯文本补翻共用提示词构造与匹配规则。人名表指纹（含匹配规则版本）参与句子缓存键和续翻状态匹配，修改规则后不能复用旧译文；本次升级有配置人名表的任务也不能复用旧版规则缓存及续翻断点；未配置人名表的任务使用空指纹，不因该规则版本前缀而失效。续翻还逐句校验原文一致、译文非空且不是原文占位。修改此流程时，验证设置切换语言、错误行提示、整句覆盖旧缓存、句内纠错、普通词不误命中、缓存及续翻失效；不得读取或改写用户的生产缓存和媒体。

转写停止或异常且程序能正常收尾时，补发包含全部已获得字幕的 `preview` 快照，并通过 `source_path` 绑定 `*.partial.srt`；冻结的表格不重绘，保存不得生成会被重试当作成品的同名字幕。快照发送不受 `checkpoint_enabled` 控制，自动写盘和下次读取断点仍受该开关控制；关闭时需手动保存快照，再次处理须启用断点才能恢复。突发崩溃或断电只能恢复已落盘检查点。回归测试同时核对断点、全文与保存路径。嵌入确认等待每 200ms 检查停止，取消时设置 `PauseResponse.cancelled` 并唤醒等待；界面跳过已取消的待显示确认，关闭正在显示的确认。启动嵌入、嵌入返回及清理原文件前均检查停止；测试须验证等待取消后不调用嵌入、无源文件删除和完成记录，并覆盖嵌入返回及清理边界。停止优先于同时发生的确认或超时；未取消时保留一小时超时自动嵌入。保护只阻止尚未执行的操作，不能回滚已删除文件，也不承诺清除所有中间产物。

转写发送的实时预览上限是 100 段。Electron 界面填满后保留已显示的行，保存、时间偏移和分页编辑使用后端推送的全文。打开字幕、切换到新文件或提交编辑会刷新预览。

本地模型管理由 `electron_backend.py` 调用 `Transcriber` 和 `local_service`。Whisper 使用已配置的本地模型，界面显示实际驻留的模型名。手动卸下 Hy-MT2、确需转写前和彻底退出时统一调用 `shutdown_service()`。Windows 上关闭外部服务前使用 `windows_service.py` 核对监听端口、进程路径、模型参数和进程身份。身份无法核实或关闭失败时保留服务并记录原因。相关回归测试见 `test_model_manager.py` 和 `test_windows_service.py`。

优先复用现有测试文件，按模块归类；字幕与媒体保护、翻译重试及断点、服务身份核实和界面状态转换的回归覆盖应保留。相同场景可合并为参数化子用例，不为减少数量而删除有效断言。新增测试文件须先说明现有文件无法容纳的原因及收益，并取得用户确认。

先运行直接相关的现有测试；涉及多个模块、出现失败或存在明确回归风险时，再运行全量测试。简单机械修改或文档修改不要求反复运行整个套件。以下命令按需选择，全量运行后无需再重复运行其中的单项测试：

```powershell
python -m unittest discover -s tools/tests
python -m unittest tools.tests.test_translator
git diff --check
```

使用虚拟环境时，将上面的 `python` 换成 `.\.venv\Scripts\python.exe`。测试数量以当前运行结果为准，历史审查记录的数量不随新增用例改写。

Electron 界面可通过 `npm start` 检查。使用独立的临时项目和媒体验证窗口、托盘和下载器导入。

- 模型加载、`ensure_running`、网络请求和媒体子进程必须模拟，防止测试启动真实服务。
- 翻译编排测试将 `translator._BACKUP_DIR` 指向临时目录；缓存、配置、断点及媒体输出也应隔离。
- 测试前后核对是否新增 `llama-server.exe` 进程；若有，先确认归属，不能终止用户已有服务。
- 单元测试通过只证明其覆盖的行为；真实 GPU 推理、媒体内嵌及视觉效果应分别报告是否验证。
- 界面颜色、主题切换或布局变更，应检查实际渲染效果；性能结论注明样本、环境和测量范围。

可疑翻译配置与密钥扫描：

```powershell
git grep -nE 'api_key|api_url|preset|sk-[A-Za-z0-9_-]{20,}' -- subtitle_app tools
```

命中后逐项检查，不机械要求零命中：ffmpeg 的 `preset` 编码参数与测试中的禁止字段断言可能合法。不得新增外部翻译端点、密钥设置或厂商适配分支；本地翻译端点由 `local_service.translation_endpoint()` 单点提供。分享扫描结果前确认没有真实密钥。

## 排障入口

| 现象 | 优先检查 |
| --- | --- |
| 启动失败 | 终端错误、Python 解释器与依赖、配置 JSON 格式 |
| 转写失败 | 模型路径、ffmpeg/ffprobe、设备与精度、`logs/subtitle_tool.log` |
| 翻译服务未启动 | `tools/llama-cpp/` 程序与 DLL、`models/hy-mt2/` GGUF、`cache/.llama-server.log` |
| 服务就绪但翻译无进展 | 实际生成日志、截断或重复响应、拆批与停止行为；健康检查成功不等于生成成功 |
| 窗口关闭后任务还在运行 | 正常托盘行为；从托盘恢复，选择「彻底退出」才能退出 |
| 内嵌失败 | ffmpeg 退出状态、输出时长验证及输入字幕；保留原媒体后再排查 |
