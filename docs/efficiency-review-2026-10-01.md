# 代码结构与效率审查（2026-10-01）

> 历史记录：以下改动、测试数、基准与提交状态仅描述 2026-10-01 审查时的情况。
> 当前使用与验证方式见 [使用说明书](使用说明书.md) 和 [开发与维护](开发与维护.md)。

审查覆盖主应用模块，由三个子智能体分别检查翻译、界面和流水线，主智能体检查
本地服务与媒体处理并复核全部改动。修改前工作区干净，保留既有功能和配置结构。

## 结构判断

入口、Qt 界面、跨线程事件、两阶段流水线、转写、翻译、媒体处理的职责已分开。
两阶段串行调度适合当前单并发本地模型，保持原有设计。未为了减少行数新增抽象或拆分模块。
本次主要消除重复处理，修复停止和样式回写中的不足；主窗口与设置模块仍较大，后续应
结合具体维护问题逐步整理。

## 已落实的改动

| 范围 | 问题 | 改动 |
| --- | --- | --- |
| 翻译编排 | 无待翻译内容也会启动模型；中文转换临时字幕写两遍 | 按需启动，转换完成后写一次；合并相同双语输出分支 |
| 翻译客户端 | 展开句子保留多余中间列表；等待请求时忽略停止 | 单趟展开；每轮等待检查停止并保存断点、取消排队任务 |
| 预览 | 每次刷新重建单元格、重复计算颜色 | 复用单元格，统一颜色计算，批量刷新暂时阻断信号与绘制 |
| 预览高亮 | 主题切换丢失高亮；改颜色触发字幕全文回写 | 保留高亮并阻断样式信号，保留原文空白和编辑索引 |
| 文件导入 | 每个新路径扫描整个列表 | 临时集合去重，保留导入顺序 |
| 文本处理 | 编码回退重读文件；断句反复扫描整个前缀 | 一次读取后解码，句点判断仅检查前一词 |
| 转写 | 停止时重复保存同一断点 | 由公共异常路径统一保存 |
| 本地服务 | 自有服务加载时误报端口占用；日志载入全部内容 | 自有进程继续等待，日志流式保留 5 条；超时使用单调时钟 |
| 媒体处理 | 多个返回分支重复清理临时文件；接受异常数值时长 | finally 统一清理，拒绝 NaN、无穷大与非正时长 |

## 验证与收益

- 修改前全量 173 项通过；修改后执行 `python -m unittest discover -s tools/tests`，187 项全部通过。
- 预览基准：本机真实离屏 Qt，300 块双语字幕，预热 5 次后重渲染 50 次；
  原版 1.7657 秒，修改后 1.0045 秒，该场景耗时减少约 43%。
- 断句基准：同进程、3000 句、87000 字符；原版 3.383301 秒，修改后 0.013601 秒。
  5000 组混合标点、数字、缩写、引号和空白输入与原版输出一致。
- 中文转换回归验证：服务启动调用由 1 次降为 0 次，临时字幕写盘由 2 次降为 1 次。
- 回归覆盖编码/换行、断点、慢请求停止、预览信号与绘制状态恢复、高亮、全文编辑映射、
  批量导入去重、临时文件清理和异常时长。
- 修复翻译测试漏模拟 `ensure_running` 的问题；原全量测试因此意外启动真实模型并留下
  子进程，已核对 PID、路径与父进程后清理本次测试创建的进程。

基准只代表上述局部场景，不代表完整 Whisper/Hy-MT2 推理速度。尚未用真实媒体执行
端到端转写、翻译和内嵌验证；建议下一步选一个短视频和一份长字幕记录实际耗时与输出。
