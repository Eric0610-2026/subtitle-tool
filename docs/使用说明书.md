## 第1章：认识这个工具

### 1.1 这是什么

这是一款 **Windows 桌面软件**，能把视频或音频里的说话声音自动转换成文字字幕，还能翻译成其他语言。

它全程在你自己的电脑上运行，**不需要把文件上传到任何网站**。你的视频、录音文件不会泄露给第三方，隐私安全有保障。

简单来说：你给它一个视频，它就能"听写"出文字稿，配上时间轴，生成标准的 `.srt` 字幕文件，可以在任何播放器上直接用。

### 1.2 它能帮你做什么

| 场景 | 以前怎么办 | 现在用它 |
|------|-----------|---------|
| **看外语视频没有字幕** | 等别人上传字幕，或者硬着头皮听 | 自动生成原文 + 翻译字幕 |
| **会议录音要整理成文字** | 自己反复听写，花费大量时间 | 一键转写出文字稿 |
| **想把视频字幕翻译成中文** | 手动复制到翻译网站，一句一句翻 | AI 自动批量翻译 |
| **处理整季电视剧（批量）** | 一个文件做一次，重复几十次 | 批量加入队列，自动排队处理 |
| **提取视频中的音频** | 找专门的格式转换工具 | 内置自动提取 |

### 1.3 核心功能速览

| 功能 | 说明 |
|------|------|
| 🎤 **语音转写** | 把语音转成文字，支持中、英、日、韩等几十种语言 |
| 🌍 **AI 翻译** | 调用 AI 接口把字幕翻译成你想要的任何语言 |
| 📝 **双语字幕** | 原文在上、译文在下，上下对照显示 |
| 📦 **MKV 内嵌** | 把字幕"嵌进"视频文件，播放器直接显示 |
| ⏯ **断点续传** | 处理到一半中断？重新打开可以接着继续 |
| ⚡ **批量处理** | 添加多个文件，一次操作全部处理完 |
| 🔍 **字幕预览** | 在软件里实时查看字幕内容 |
| 📊 **实时进度** | 每个步骤都有进度条 |

### 1.4 技术原理（通俗版）

整个工具处理一个视频的过程，只有 **4 个步骤**：

```
视频文件 → [提取音频] → [AI 听写] → [翻译] → 字幕文件
```

**第一步：从视频中提取音频**  
调用 ffmpeg（一款免费的音视频处理工具）把声音单独提取出来，变成一段纯粹的音频文件。

**第二步：用 AI 模型"听写"音频**  
提取出来的音频会被送入 **Whisper** 模型（由 OpenAI 开发）。这个模型经过海量语音数据训练，能把音频里的说话声一个字一个字地"听写"成文字。

> 打个比方：就像你请了一位同声传译人员，让他一边听一边打字记录。而且这位"员工"不需要联网，就在你的电脑里工作。

**第三步：调用 AI 接口翻译字幕（可选）**  
勾选了翻译功能后，工具把文字逐句发送给 AI 翻译服务（如 DeepSeek），翻译成你指定的语言。

> 注意：这一步需要网络连接。但发送的只是文字，不是你的视频文件。

**第四步：生成 `.srt` 字幕文件**  
把文字和时间轴信息组合在一起，生成标准的 `.srt` 字幕文件，任何播放器都可加载。

## 第2章：安装准备

> **预估耗时**：20~40 分钟（主要取决于下载模型的速度）

### 2.1 你需要准备什么

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10 或 11 | 同左 |
| 硬盘空间 | 至少 10GB 可用 | 20GB 以上更宽裕 |
| 内存 | 8GB | 16GB 或更高 |
| 显卡 | 无要求（纯 CPU 也能跑） | **NVIDIA 显卡，4GB+ 显存**（可大幅提速） |
| 网络 | 安装和下载模型时需要 | 宽带或光纤 |

> 💡 **关于显卡**：有 NVIDIA 显卡（GTX 1060 及以上）转写速度快 5~10 倍。没有独立显卡，CPU 也能运行，只是慢一些（10 分钟视频约需 15~30 分钟）。AMD 显卡暂不支持 GPU 加速。

### 2.2 安装 Python（Windows 版）

Python 是这个工具的运行基础，就像手机需要操作系统一样。

**步骤 1：下载 Python**

1. 打开浏览器，访问 `https://www.python.org/downloads/windows/`
2. 找到 **Python 3.10.x** 或 **3.11.x** 版本
3. 点击 **Download Windows installer (64-bit)** 链接

**步骤 2：安装 Python**

1. 双击下载的安装包
2. **⚠️ 最重要的一步！** 在安装窗口最底部，**务必勾选** `☑ Add Python 3.x to PATH`
   - 如果不勾选，后面会无法运行工具
3. 点击 **Install Now**
4. 等待安装完成，出现 **"Setup was successful"** 后点击 **Close**

> 📸 截图位置：[Python 安装界面，用红框标注 "Add Python to PATH"]

**步骤 3：验证安装**

1. 按键盘 `Win + R`，输入 `cmd`，回车
2. 在黑色窗口中输入：
   ```
   python --version
   ```
3. 如果显示 `Python 3.10.x` 之类的版本号，说明成功

> 如果提示 `'python' 不是内部或外部命令`，说明第 2 步忘记打勾了。重新运行安装程序勾上即可。

### 2.3 准备 ffmpeg（音视频处理工具）

ffmpeg 用于从视频中提取音频、内嵌字幕。应用会按 **应用目录 → `tools/` 目录 → 系统 PATH** 的顺序查找 ffmpeg 和 ffprobe，任一处找到即用。

**方式一：使用系统已安装的 ffmpeg（推荐）**

如果电脑已安装 ffmpeg（含 ffprobe）并已加入 PATH（命令行执行 `ffmpeg -version` 有输出即满足），无需任何额外文件。

**方式二：放入 `tools/` 目录**

1. 打开 `https://ffmpeg.org/download.html`
2. 找到 Windows 图标，点击进入
3. 下载 `ffmpeg-release-full.7z`
4. 解压后找到 `bin/` 文件夹，复制 `ffmpeg.exe` 和 `ffprobe.exe`
5. 粘贴到本项目的 `tools/` 文件夹中

> ⚠️ 若采用 `tools/` 目录方式，`ffmpeg.exe` 和 `ffprobe.exe` **缺一不可**。

### 2.4 下载 Whisper 模型

Whisper 模型是语音识别的"大脑"，约 **1.6 GB**。

**下载地址**：  
https://www.modelscope.cn/models/pengzhendong/faster-whisper-large-v3-turbo

**操作步骤**：

1. 打开上面的网址，点击「下载全部」
2. 在项目目录下创建 `models/faster-whisper-large-v3-turbo/` 文件夹
3. 将下载的所有文件放入该文件夹

最终目录结构：
```
subtitle-tool/
  models/
    faster-whisper-large-v3-turbo/
      model.bin          ← 核心模型文件（约 1.6 GB）
      tokenizer.json
      config.json
      vocabulary.json
      ...（其他文件）
```

> 如果下载速度慢，可以尝试用迅雷下载。

### 2.5 配置 API 密钥（翻译用）

> ⚠️ **仅在使用翻译功能时需要**。如果只做语音转写，可以跳过本节。

以 **DeepSeek** 为例：

1. 访问 `https://platform.deepseek.com/` 注册账号
2. 登录后在控制台左侧找到 **"API Keys"**
3. 点击 **"Create API Key"**，取名后复制生成的密钥（以 `sk-` 开头）
4. 打开 `subtitle_app/config.example.json`，另存为 `config.json`
5. 用记事本打开 `config.json`，找到 `"api_key"` 字段，粘贴你的密钥

```json
{
  "translation": {
    "api_url": "https://api.deepseek.com/v1/chat/completions",
    "api_key": "sk-你的密钥",
    "model": "deepseek-chat",
    "target_lang": "zh"
  }
}
```

6. 保存文件（Ctrl + S）

> DeepSeek API 价格非常便宜（翻译 100 万字符约 1~2 元），首次注册有免费额度。

## 第4章：生成你的第一个字幕

### 4.1 准备视频文件

找一个 1~5 分钟的短视频（MP4、MKV 等格式均可）或录音文件（MP3、WAV）。

> 建议先用短文件试手，熟悉流程后再处理长视频。

### 4.2 添加文件

**方法一：拖拽添加**

1. 打开视频所在的文件夹
2. 用鼠标左键按住视频文件
3. 拖到工具窗口的文件列表区域，松开鼠标
4. 文件出现在列表中

**方法二：按钮添加**

1. 点击视频目录旁的「浏览」选择文件夹
2. 点击「扫描」自动列出文件夹下的媒体文件

### 4.3 配置翻译（可选）

如果不需要翻译，确保「开启翻译」**未勾选**。

如果需要翻译：
1. 勾选「开启翻译」
2. 点击「设置」按钮
3. 填入 API 地址和密钥（见第 2.5 节）
4. 点击「确定」

### 4.4 开始处理

点击底部 **「▶ 开始处理」**。工具依次执行：

| 阶段 | 说明 | 耗时 |
|------|------|------|
| ① 加载模型 | 加载 Whisper 到显存 | 2~10 秒（首次） |
| ② 提取音频 | 从视频中分离声音 | 几秒~几十秒 |
| ③ 语音转写 | AI 听写出文字 | 与视频时长成正比 |
| ④ AI 翻译 | 逐段翻译（如开启） | 几十秒~几分钟 |

### 4.5 查看进度

处理过程中，你可以看到：

- **总进度条**：所有文件的整体完成度
- **转写进度条**：当前文件语音识别的进度
- **翻译进度条**：当前文件翻译的进度
- **详情文字**：当前处理阶段、字幕段数、时间信息
- **预览窗口**：实时滚动显示字幕内容
- **日志窗口**：详细处理步骤记录

### 4.6 处理完成

所有阶段到达 100%，工具弹出通知「所有任务处理完成！」。

打开视频所在文件夹，会看到生成的字幕文件：

```
你的视频.mp4
你的视频.zh.srt            ← 中文翻译字幕
你的视频.ja.srt            ← 日语原文转写字幕
你的视频.ja.zh.srt         ← 日中对双语字幕
```

> SRT 是最常用的字幕格式，几乎所有播放器都支持。

### 4.7 查看字幕

**方法一：播放器自动加载**  
用 VLC 或 PotPlayer 打开视频，播放器通常会自动加载同目录下的 .srt 文件。

**方法二：记事本打开**

右键 `.srt` 文件 → 打开方式 → 记事本：

**方法三：工具内置预览**  
工具预览窗口会实时显示字幕内容。

## 第5章：添加文件的方式

### 5.1 拖拽添加（最直观）

这是最快捷的方式：

1. 打开文件资源管理器，找到视频或音频文件
2. 选中一个或多个文件（按住 Ctrl 多选）
3. 用鼠标左键拖拽到工具的文件列表区域
4. 松手即可添加

支持的文件格式：

| 视频格式 | 音频格式 |
|---------|---------|
| .mp4, .mkv, .avi, .mov, .wmv, .flv | .mp3, .wav, .m4a, .flac, .aac, .ogg |

### 5.2 按钮选择

1. 点击「浏览」按钮，选择视频所在文件夹
2. 点击「扫描」按钮，工具自动列出该文件夹下的所有媒体文件
3. 文件会自动加入队列

### 5.3 文件夹扫描

- 扫描时会自动递归查找子文件夹
- 只识别支持的媒体格式（见 5.1 节表格）
- 扫描结果会一次性加入队列

### 5.4 文件队列管理

| 操作 | 方法 |
|------|------|
| 移除单个文件 | 选中后按 Delete 键 |
| 清空所有文件 | 右键菜单 → 清空列表 |
| 调整处理顺序 | 列表顺序 = 处理顺序，暂不支持拖拽排序 |

### 5.5 忽略已完成文件

工具会自动记录已处理的文件，记录存储在 `.subtitle_progress.json` 中。下次启动或添加文件时，已处理文件会被标记为"已忽略"，不会出现在队列中。

> 如果想重新处理某个文件，可以在设置中清除进度记录。

## 第6章：处理过程详解

### 6.1 阶段一：提取音频

工具调用 ffmpeg 从视频中提取音频轨道：

- 输出格式：WAV（16kHz 采样率，单声道）
- 耗时：通常几秒到几十秒（取决于视频时长）
- 临时文件存放在系统临时目录，处理完后自动删除

### 6.2 阶段二：加载 Whisper 模型

- **首次处理**：需要将模型加载到显存/内存（约 2~10 秒）
- **后续处理**：模型已缓存在显存中，无需重新加载
- 底部状态标签显示 **🧠 模型：已加载 / 未加载**
- 如果显存不足（如同时运行其他 GPU 程序），可以点击 **✕ 卸载模型** 释放

### 6.3 阶段三：语音转写

这是最耗时的阶段：

- AI 逐段识别音频内容
- 实时预览字幕逐句出现
- 检测到的语言显示在进度区（如 🎤 日语）
- 支持语言缓存（同批同语种视频后续文件跳过检测）

### 6.4 阶段四：AI 翻译（可选）

开启翻译时：

- 调用 AI API 逐段翻译字幕
- 支持批量发送（batch_size 可调）提高效率
- 翻译结果自动缓存，避免重复翻译同一句话
- 支持断点续翻（中断后在断点处继续）

### 6.5 进度条含义

| 进度条 | 含义 |
|--------|------|
| 总进度 | 所有文件的加权平均（转写权重 80%，翻译 20%） |
| 转写进度 | 当前文件语音识别的完成度 |
| 翻译进度 | 当前文件翻译的完成度 |

### 6.6 停止与继续

- 点击 **⏹ 停止** 中断当前处理
- 已完成的文件不会丢失
- 重新点击 **▶ 开始处理**，工具会跳过已完成文件，从未完成的开始
- 长视频中断后从断点恢复（断点续转）

### 6.7 并行流水线模式

开启「并行流水线」后：

- **转写线程** 1 个（GPU 专注转写）
- **翻译线程** 最多 3 个（并发调用 API）
- 转写和翻译同时进行：一个文件翻译时，下一个文件已开始转写
- 关闭后为串行模式：一个文件完全处理完再处理下一个

## 第7章：理解输出文件

### 7.1 SRT 字幕格式

SRT（SubRip Text）是最通用的字幕格式：

```
序号
开始时间 --> 结束时间
字幕文本

序号
开始时间 --> 结束时间
字幕文本
```

时间格式：`时:分:秒,毫秒`

示例：
```
1
00:00:01,000 --> 00:00:04,500
Hello, welcome to this tutorial.

2
00:00:05,000 --> 00:00:08,200
Today we'll learn how to use this tool.
```

### 7.2 双语字幕结构

开启翻译后生成的双语字幕：

```
1
00:00:01,000 --> 00:00:05,000
こんにちは、元気ですか？
你好，最近怎么样？
```

原文在上，译文在下，上下对照。

### 7.3 文件命名规则

| 文件 | 含义 |
|------|------|
| `视频名.ja.srt` | 原文转写（日语） |
| `视频名.zh.srt` | 翻译结果（中文） |
| `视频名.ja.zh.srt` | 双语（日语+中文） |
| `视频名.partial.srt` | 断点续传临时文件 |
| `视频名.translate_state.json` | 翻译断点状态文件 |

语言代码：zh（中文）、en（英语）、ja（日语）、ko（韩语）、fr（法语）等。

### 7.4 临时文件和备份

| 路径 | 用途 |
|------|------|
| `*.partial.srt` | 转写断点文件，中断后恢复用 |
| `cache/.subtitle_translation_cache.json` | 翻译缓存，避免重复调用 API |
| `logs/srt_backup/` | 字幕备份目录，处理前自动备份原文 |

## 第8章：语音识别设置

打开设置对话框（点击底部「设置」按钮），在「🎙 语音识别」区域：

如果下载了其他版本的模型（如 faster-whisper-small），选择对应的文件夹即可。

### 8.2 识别语言

| 选项 | 说明 | 推荐场景 |
|------|------|---------|
| `auto`（默认） | 自动检测视频语言 | 不确定视频语种时 |
| `zh` | 指定中文 | 确定是中文视频 |
| `en` | 指定英语 | 确定是英文视频 |
| `ja` | 指定日语 | 确定是日文视频 |
| `ko` | 指定韩语 | 确定是韩文视频 |

> 指定语言可以提高识别准确率，且节省语言检测时间。

### 8.3 设备选择

| 选项 | 说明 |
|------|------|
| `CUDA`（推荐） | 使用 NVIDIA 显卡加速，速度快 5~10 倍 |
| `CPU` | 没有 NVIDIA 显卡时使用，速度较慢 |

### 8.4 计算精度

| 精度 | 显存占用 | 速度 | 准确率 | 推荐 |
|------|---------|------|--------|------|
| `int8_float16` | 低 | 快 | 高 | **推荐** |
| `float16` | 较低 | 最快 | 较高 | 显存充足时 |
| `int8` | 最低 | 较快 | 中等 | 显存不足时 |
| `float32` | 最高 | 最慢 | 最高 | 追求极致精度 |

### 8.5 VAD 过滤

VAD（Voice Activity Detection，语音活动检测）：

- **开启**（推荐）：自动跳过无声片段，提高识别质量
- **关闭**：处理包含背景音乐或特殊音效的视频时尝试关闭

### 8.6 提取音频

- 处理视频文件时，需要从视频中提取音频
- 纯音频文件（如 MP3、WAV）不需要此步骤
- 建议保持开启

## 第11章：批量处理

### 11.1 什么是批量处理

一次添加多个视频/音频文件，工具自动逐个处理。这是处理大量文件（如整季电视剧、多个会议录音）的标准方式。

### 11.2 批量添加文件

- **拖拽多个文件**：在文件管理器中选中多个文件，一起拖入窗口
- **扫描文件夹**：选择文件夹后点击「扫描」，自动添加所有媒体文件
- **混合添加**：视频和音频文件可以混合添加

### 11.3 并行流水线加速

默认设置下：

| 参数 | 值 | 说明 |
|------|-----|------|
| 转写线程 | 1 个 | GPU 专注做一件事 |
| 翻译线程 | 最多 3 个 | 并发调用 API 翻译 |
| 流水线深度 | 2 | 翻译 N 时转写 N+1 已经开始 |

这意味着：当第一个文件在翻译时，第二个文件已经开始转写。两者互不阻塞。

### 11.4 批量处理建议

| 场景 | 建议 |
|------|------|
| 同一语种（如整季日剧） | 一次添加，效率最高 |
| 不同语种混搭 | 分开批次处理 |
| 长视频（1 小时+） | 单独处理，方便监控进度 |
| 短视频（< 5 分钟） | 批量处理，开并行流水线 |

## 第12章：MKV 字幕内嵌

### 12.1 什么是 MKV 内嵌

MKV 是一种多媒体容器格式。内嵌字幕指将字幕文件"装入"MKV 视频中，成为视频的"内置字幕轨道"。

**优点：**
- 播放时可在播放器中自由切换字幕轨道
- 不修改视频画面（无损）
- 文件大小增加极少（几 KB）

### 12.2 手动嵌入

1. 点击 **「📦 嵌入」** 按钮
2. 选择一个或多个视频文件
3. 为每个视频选择对应的 `.srt` 字幕文件
4. 点击「嵌入」开始处理
5. 生成 `视频名.embedded.mkv`

### 12.3 自动嵌入

在设置中配置「处理完成后自动嵌入」：

- 每个文件处理完成后自动调用 ffmpeg 嵌入字幕
- 嵌入完成后可选择自动删除原始 SRT 文件
- 生成格式：`视频名.mkv`（保留原文件名，直接嵌入）

### 12.4 查看内嵌字幕

| 播放器 | 操作 |
|--------|------|
| **VLC** | 菜单 → 字幕 → 字幕轨道 → 选择对应语言 |
| **PotPlayer** | 右键 → 字幕 → 字幕选择 |

## 第13章：断点续传与缓存

### 13.1 语音转写断点续转

- 处理长视频时，每生成一段字幕就保存到 `*.partial.srt`
- 如果中断（停电、停止、崩溃），下次处理同一文件时自动恢复
- 从断点处继续转写，不会从头开始
- 恢复时传递前几句作为上下文，保持识别连贯性

### 13.2 翻译缓存

- 每条翻译结果都缓存到 `cache/.subtitle_translation_cache.json`
- 下次遇到相同原文时直接使用缓存，不重复调用 API
- 节省费用和等待时间
- 缓存超过 10,000 条时自动清理最旧条目

### 13.3 翻译断点续翻

- 翻译过程中定期保存状态到 `*.translate_state.json`
- 中断后重新开始翻译时自动跳过已翻译的句子
- 与转写断点互不干扰

### 13.4 缓存管理

在「设置」→「缓存管理」中可以：

- 查看当前缓存状态
- **清除翻译缓存**：下次重新调用 API 翻译
- **清除状态文件**：断点续翻功能重置

处理完成后，工具自动分析字幕质量。检查项包括：

| 检查项 | 说明 |
|--------|------|
| 空字幕条目 | 是否存在内容为空的行 |
| 超长停顿 | 字幕间是否有超过 5 秒的间隔（可能漏译）|

### 14.3 常见质量问题处理

| 问题 | 可能原因 | 解决方法 |

| 漏译 | API 配额不足或网络中断 | 检查网络，重新翻译 |
| 时间轴不准 | VAD 参数不匹配 | 调整 VAD 设置 |
| 识别错字 | 语言检测错误 | 指定视频语言 |
| 空白字幕 | 音频噪音过多 | 开启 VAD 过滤 |

## 第16章：模型管理

### 16.1 模型下载与选择

工具默认使用 `faster-whisper-large-v3-turbo`（速度和精度平衡）。其他可选模型：

| 模型 | 大小 | 速度 | 准确率 | 推荐场景 |
|------|------|------|--------|---------|
| `tiny` | ~150 MB | 最快 | 较低 | 实时录音转写 |
| `base` | ~300 MB | 快 | 中等 | 快速试听 |
| `small` | ~500 MB | 较快 | 中等 | 普通日常使用 |
| `medium` | ~1.5 GB | 中等 | 较高 | 质量优先 |
| `large-v3` | ~3 GB | 慢 | 最高 | 极致质量 |
| `large-v3-turbo` | ~1.6 GB | 较快 | 高 | **推荐**（速度和精度的平衡） |

模型下载渠道：
- **ModelScope**：https://www.modelscope.cn （国内推荐，速度快）
- **HuggingFace**：https://huggingface.co （国际推荐）

### 16.2 模型缓存与持久驻留

- 模型在**批次间持久驻留**显存，不会在 stop 时卸载
- 同一会话中第二次处理不需要重新加载
- 显存占用约 2~4 GB（取决于模型和精度）

- 点击底部 **「✕ 卸载模型」** 按钮手动释放

- 切换设备或精度时会自动切换模型

### 16.4 多模型管理

- 修改 `config.json` 中的 `model_dir` 使用不同模型
- 不同 key 的模型会分别缓存，切换时各不干扰

## 第17章：故障排除

### 17.1 日志查看

日志是排查问题最重要的手段。

**日志位置**：运行过程中，日志实时显示在工具底部的日志面板中。

**日志级别**：

| 级别 | 颜色 | 含义 |
|------|------|------|
| INFO | 正常 | 常规运行信息 |
| WARNING | 黄色 | 警告，不影响运行但需要注意 |
| ERROR | 红色 | 错误，导致任务失败 |

**导出日志**：点击底部 **「📤 导出」** 按钮保存日志到文件，方便分享排查。

### 17.2 常见错误及解决方案

| 错误现象 | 可能原因 | 解决方法 |
|---------|---------|----------|
| 找不到模型文件 | 模型未下载或路径错误 | 下载模型放到 `models/` 目录，检查 `model_dir` 配置 |
| CUDA 内存不足 | 显存不够加载模型 | 换 CPU 模式、降低精度、使用更小模型 |
| API 认证失败 | API Key 无效 | 检查 API Key 是否正确，是否已过期 |
| ffmpeg 未找到 | 缺少音视频处理工具 | 安装 ffmpeg 并加入 PATH，或将 ffmpeg.exe 放入 `tools/` 目录 |
| 翻译超时 | 网络问题或 API 响应慢 | 检查网络连接，减小 `batch_size` |
| 中文显示乱码 | 编码问题 | 确保文件保存为 UTF-8 编码 |

# 附录

## 附录 A：常见问题 FAQ

**A.1 软件安全吗？会上传我的文件吗？**

语音转写完全在本地运行，**不上传任何音频/视频文件**。翻译时仅发送字幕文本到 API。代码完全开源，可自行审查。

**A.2 支持哪些文件格式？**

视频：MP4、MKV、AVI、MOV、WMV、FLV 等。  
音频：MP3、WAV、M4A、FLAC、AAC 等。

**A.3 为什么处理速度很慢？**

可能原因：
- 使用 CPU 而不是 GPU → 切换到 CUDA
- 视频太长 → 分批处理或开启并行流水线
- 开启了翻译 → 翻译需要 API 响应时间

**A.4 必须联网吗？**

语音转写不需要联网。AI 翻译需要联网调用 API。

**A.5 支持 Mac 或 Linux 吗？**

目前仅支持 Windows。从源码看，核心逻辑跨平台，但 GUI 部分使用了 PySide6（跨平台），理论上可在 Mac/Linux 运行，但未经过充分测试。

**A.6 字幕时间轴不对怎么办？**

- 开启 VAD 过滤
- 在设置中指定视频语言
- 调整 `silence_gap_seconds` 参数（config.json 中）

**A.7 翻译质量不好怎么办？**

- 更换更强大的翻译模型
- 减少 `batch_size` 提高单条质量
- 检查 API 服务商的可用性

**A.8 如何处理超长视频（2 小时+）？**

工具支持断点续转，中断后重新开始会从断点继续。也可以手动将视频分段处理。

**A.9 模型文件太大怎么办？**

可以使用 smaller 版本模型（如 `faster-whisper-small`），大小约 500 MB，识别速度更快。

**A.10 如何卸载？**

直接删除整个项目文件夹即可。Python 环境可按需卸载（控制面板 → 程序和功能 → Python）。

## 附录 B：文件格式参考

### B.1 SRT 格式

SRT（SubRip Text）是最通用的字幕格式：

```
序号
开始时间 --> 结束时间
字幕文本

序号
开始时间 --> 结束时间
字幕文本
（空行分隔）
```

规范：
- 序号为从 1 开始的连续整数
- 时间格式：`小时:分钟:秒,毫秒`
- 字幕文本可包含多行
- 每条字幕之间用空行分隔
